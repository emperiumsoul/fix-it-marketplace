# Fix it Marketplace

A local services marketplace in Ghana with intelligent service search, connecting customers with trusted local providers for plumbing, cleaning, electrical repairs, painting, moving, and general household tasks.

## Tech Stack
- **Framework**: Next.js 16 (App Router) & React 19
- **Styling**: Tailwind CSS v4 with custom design system tokens
- **Icons**: Lucide React
- **Typography**: Satoshi (Body/UI) & Plus Jakarta Sans / Grotesque (Headings)

## Getting Started
First, install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the design system and marketplace.
